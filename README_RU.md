# 143 Music

**Более удобный десктопный клиент для YouTube Music.**

[**English**](./README.md) · [**Русский**](./README_RU.md)

143 Music использует YouTube Music как музыкальный сервис, но заменяет значительную часть десктопного интерфейса своим UI, плеером и дополнительными функциями.

## Что такое 143 Music?

143 Music — десктопный Electron-клиент вокруг YouTube Music. Идея простая: оставить каталог, рекомендации, аккаунт и движок воспроизведения YouTube Music, но сделать приложение похожим на нормальный отдельный музыкальный плеер.

Это не просто тема поверх одной страницы. У 143 Music свой интерфейс для Home, поиска, артистов, альбомов, плейлистов, очереди, нижнего плеера, Now Playing, текстов песен и настроек.

## Основные функции

- **143 UI** — собственная боковая панель, Home, поиск, библиотека, страницы артистов, альбомов и плейлистов.
- **Свой Now Playing** — обложка, синхронные тексты, текущий плейлист / Up Next и альбом на одном экране.
- **Персональный Home** — настоящие рекомендации YouTube Music, но в интерфейсе 143 Music.
- **Управление качеством аудио** — стандарт YouTube Music, Premium HQ AAC и экспериментальный Premium HQ Opus.
- **Синхронные тексты песен**.
- **Google account controls** — вход и переключение аккаунта прямо из верхней панели 143 Music.
- **Discord Rich Presence**.
- **OBS Now Playing overlay** для стримов.
- **Локальная / офлайн-библиотека** — импорт Opus, FLAC, M4A, MP3, OGG, WebM, WAV и AAC.
- **Десктопная интеграция** — медиа-кнопки, трей, сохранение настроек и нормальное окно приложения.

## Установка на Windows

### 1. Скачать

1. Открой страницу [**Releases**](https://github.com/143kmh/143-youtube-music/releases).
2. Открой самый новый релиз.
3. Скачай файл с названием примерно такого вида:

```text
143-Music-Setup-<version>-x64.exe
```

4. Дважды кликни по скачанному `.exe`.
5. При желании выбери свою папку установки.
6. Нажми **Install / Установить**.
7. Запусти **143 Music**.
8. Нажми кнопку аккаунта справа сверху и войди в Google / YouTube Music.

На этом всё.

## Windows пишет «Windows protected your PC» / «Система Windows защитила ваш компьютер»

Такое может происходить на первых публичных версиях, потому что установщик пока **не подписан цифровой подписью**.

Обычное предупреждение Microsoft Defender SmartScreen **не означает, что Windows нашла вирус**. Оно означает, что Windows пока не знает издателя этого `.exe` и у файла нет накопленной репутации.

Если установщик скачан именно со страницы **Releases** этого репозитория:

1. Запусти установщик.
2. Если появилось синее окно **Windows protected your PC / Система Windows защитила ваш компьютер**, нажми **More info / Подробнее**.
3. Убедись, что приложение называется **143 Music**.
4. Нажми **Run anyway / Выполнить в любом случае**.
5. Дальше устанавливай как обычную программу.

### Важно: SmartScreen и обнаружение вируса — не одно и то же

Синее окно **Windows protected your PC**, сообщение **Unknown publisher / Неизвестный издатель** — это предупреждение о неподписанном неизвестном приложении.

Если же **Windows Security / Безопасность Windows** прямо пишет, что обнаружен **virus**, **trojan**, **malware** или **potentially unwanted application**, не нужно вслепую отключать Defender и добавлять всю папку в исключения. Сначала проверь, что файл действительно скачан из официального Releases этого репозитория, и сообщи о срабатывании, чтобы сборку можно было проверить.

На некоторых Windows 11 включён **Smart App Control**. Он может полностью блокировать неизвестные неподписанные приложения и не показывать кнопку **Run anyway**. У этого режима нет нормального исключения для одного конкретного приложения. В таком случае лучше не отключать системную защиту только ради 143 Music: можно собрать приложение из исходников или дождаться подписанного релиза.

## Если Releases пока пустой

Значит готовый установщик ещё не опубликован. Приложение можно собрать самостоятельно.

### Сборка из исходников

Нужно:

- Windows 10 или Windows 11
- Node.js 22 или новее
- pnpm 11 или новее
- Git

Открой **PowerShell** и выполни команды по очереди:

```powershell
git clone https://github.com/143kmh/143-youtube-music.git
cd 143-youtube-music
pnpm install --frozen-lockfile
pnpm dist:win
```

Готовый установщик появится в папке `pack` внутри проекта.

Если нужно просто запустить приложение локально без создания установщика:

```powershell
pnpm build
pnpm start
```

## Первый запуск

1. Нажми кнопку аккаунта справа сверху, чтобы войти или переключить Google-аккаунт.
2. Открой **Home**, чтобы загрузить свои рекомендации YouTube Music.
3. В **Settings** можно выбрать качество аудио, цвет интерфейса, Discord Rich Presence и другие параметры.
4. Нажми на обложку трека или используй Karaoke / Queue, чтобы открыть собственный экран **Now Playing**.

Для функций YouTube Music, которые доступны только подписчикам Premium, включая соответствующие режимы высокого качества, нужен YouTube Music Premium.

## OBS overlay

В 143 Music есть локальный Now Playing overlay для OBS.

1. Оставь 143 Music запущенным.
2. В OBS добавь **Browser Source / Источник браузера**.
3. Укажи адрес:

```text
http://127.0.0.1:14321/overlay
```

4. Для начала поставь размер **520 × 140**.
5. Custom CSS оставь пустым.

Overlay работает только на твоём компьютере и показывает обложку, название трека, артиста, альбом, состояние воспроизведения и прогресс.

## Локальная / офлайн-библиотека

Открой **Downloads** в боковом меню и нажми **Import audio**. Импортированные файлы копируются в локальную библиотеку 143 Music и могут воспроизводиться без интернета.

Поддерживаются Opus, FLAC, M4A, MP3, OGG, WebM, WAV и AAC.

Локальная библиотека **не извлекает и не скачивает защищённые потоки YouTube Music**.

## Для разработчиков

Основная функциональность проекта находится в `src/features` и регистрируется через `src/core/features.ts`.

Полезные команды:

```bash
pnpm dev
pnpm build
pnpm start
pnpm dist:win
pnpm dist:linux
pnpm dist:mac
pnpm dist:mac:arm64
```

Часть функций зависит от внутренних DOM/API YouTube Music. Google может менять их независимо от проекта, поэтому некоторые интеграции иногда могут требовать обновления.
