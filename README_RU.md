# 143 Music

**Лёгкий десктопный клиент для YouTube Music со своим UI и принудительным Opus.**

[**English**](./README.md) · [**Русский**](./README_RU.md)

143 Music оставляет каталог, рекомендации и аккаунт YouTube Music, но заменяет значительную часть десктопного опыта своим более чистым интерфейсом и дополнительными функциями.

Клиент оптимизирован под низкую фоновую нагрузку и даёт прямой контроль над качеством аудио, включая принудительный Opus, когда YouTube его отдаёт.

## Зачем 143 Music?

- **Низкая фоновая нагрузка** — неактивные экраны не продолжают делать лишнюю работу, а постоянный polling сокращён.
- **Принудительный Opus** — 143 Music может выбрать лучший Opus-поток, который отдаёт YouTube, вместо более слабого десктопного fallback.
- **Свой десктопный UI** — Home, поиск, артисты, альбомы, плейлисты, очередь, плеер, Now Playing, тексты и настройки.

### Почему Opus?

В наших тестах обычный YouTube Music на ПК часто выбирал **AAC-LC примерно 128–130 kbps**. С включённым Opus 143 Music использует более качественный Opus-поток, который уже отдаёт YouTube, включая **itag 774** на подходящем Premium-воспроизведении.

Opus эффективнее AAC-LC при сопоставимом битрейте, а доступный Opus-поток может ещё и иметь примерно вдвое больший bitrate. В итоге меньше агрессивного сжатия и артефактов, лучше сохраняются детали. Это всё ещё lossy-аудио, но заметно более качественный вариант, чем 128 kbps AAC fallback.

## Основные функции

- **Низкая фоновая нагрузка**
- **Принудительный Opus**
- **143 UI** — Home, поиск, библиотека, артисты, альбомы и плейлисты
- **Свой Now Playing** — обложка, синхронные тексты, текущий плейлист / Up Next и полный альбом
- **Персональный Home** — настоящие рекомендации YouTube Music в интерфейсе 143 Music
- **Синхронные тексты песен**
- **Google account controls**
- **Discord Rich Presence**
- **OBS Now Playing overlay**
- **Локальная / офлайн-библиотека** — Opus, FLAC, M4A, MP3, OGG, WebM, WAV и AAC
- **Десктопная интеграция** — медиа-кнопки, трей и сохранение настроек

> Под «лёгким» здесь имеется в виду прежде всего **низкая нагрузка во время работы и в idle**. 143 Music всё ещё построен на Electron, поэтому размер установленного приложения включает Electron/Chromium.

## Установка на Windows

### 1. Скачать

1. Открой страницу [**Releases**](https://github.com/143kmh/143-youtube-music/releases).
2. Открой самый новый релиз.
3. Скачай файл с названием примерно такого вида:

```text
143-Music-Setup-<version>-x64.exe
```

4. Дважды кликни по скачанному `.exe`.
5. При желании выбери свою папку установки.
6. Нажми **Install / Установить**.
7. Запусти **143 Music**.
8. Нажми кнопку аккаунта справа сверху и войди в Google / YouTube Music.

На этом всё.

## Windows пишет «Windows protected your PC» / «Система Windows защитила ваш компьютер»

Такое может происходить на первых публичных версиях, потому что установщик пока **не подписан цифровой подписью**.

Обычное предупреждение Microsoft Defender SmartScreen **не означает, что Windows нашла вирус**. Оно означает, что Windows пока не знает издателя этого `.exe` и у файла нет накопленной репутации.

Если установщик скачан именно со страницы **Releases** этого репозитория:

1. Запусти установщик.
2. Если появилось синее окно **Windows protected your PC / Система Windows защитила ваш компьютер**, нажми **More info / Подробнее**.
3. Убедись, что приложение называется **143 Music**.
4. Нажми **Run anyway / Выполнить в любом случае**.
5. Дальше устанавливай как обычную программу.

### Важно: SmartScreen и обнаружение вируса — не одно и то же

Синее окно **Windows protected your PC**, сообщение **Unknown publisher / Неизвестный издатель** — это предупреждение о неподписанном неизвестном приложении.

Если же **Windows Security / Безопасность Windows** прямо пишет, что обнаружен **virus**, **trojan**, **malware** или **potentially unwanted application**, не нужно вслепую отключать Defender и добавлять всю папку в исключения. Сначала проверь, что файл действительно скачан из официального Releases этого репозитория, и сообщи о срабатывании, чтобы сборку можно было проверить.

На некоторых Windows 11 включён **Smart App Control**. Он может полностью блокировать неизвестные неподписанные приложения и не показывать кнопку **Run anyway**. В таком случае лучше использовать сборку из исходников или дождаться подписанного релиза, а не отключать системную защиту.

## Если Releases пока пустой

Значит готовый установщик ещё не опубликован. Приложение можно собрать самостоятельно.

### Сборка из исходников

Нужно:

- Windows 10 или Windows 11
- Node.js 22 или новее
- pnpm 11 или новее
- Git

Открой **PowerShell** и выполни команды по очереди:

```powershell
git clone https://github.com/143kmh/143-youtube-music.git
cd 143-youtube-music
pnpm install --frozen-lockfile
pnpm dist:win
```

Готовый установщик появится в папке `pack` внутри проекта.

Если нужно просто запустить приложение локально без создания установщика:

```powershell
pnpm build
pnpm start
```

## Первый запуск

1. Нажми кнопку аккаунта справа сверху, чтобы войти или переключить Google-аккаунт.
2. Открой **Home**, чтобы загрузить свои рекомендации YouTube Music.
3. В **Settings** можно выбрать качество аудио, цвет интерфейса и Discord Rich Presence.
4. Включи **Opus**, если хочешь лучший Opus-поток, который YouTube отдаёт твоей сессии.
5. Нажми на обложку трека или используй Karaoke / Queue, чтобы открыть свой экран **Now Playing**.

Для Premium-only режимов воспроизведения и high-quality потоков нужен YouTube Music Premium.

## OBS overlay

В 143 Music есть локальный Now Playing overlay для OBS.

1. Оставь 143 Music запущенным.
2. В OBS добавь **Browser Source / Источник браузера**.
3. Укажи адрес:

```text
http://127.0.0.1:14321/overlay
```

4. Для начала поставь размер **520 × 140**.
5. Custom CSS оставь пустым.

Overlay работает только на твоём компьютере и показывает обложку, название трека, артиста, альбом, состояние воспроизведения и прогресс.

## Локальная / офлайн-библиотека

Открой **Downloads** в боковом меню и нажми **Import audio**. Импортированные файлы копируются в локальную библиотеку 143 Music и могут воспроизводиться без интернета.

Поддерживаются Opus, FLAC, M4A, MP3, OGG, WebM, WAV и AAC.

Локальная библиотека **не извлекает и не скачивает защищённые потоки YouTube Music**.

## Для разработчиков

Основная функциональность проекта находится в `src/features` и регистрируется через `src/core/features.ts`.

Полезные команды:

```bash
pnpm dev
pnpm build
pnpm start
pnpm dist:win
pnpm dist:linux
pnpm dist:mac
pnpm dist:mac:arm64
```

Некоторые интеграции зависят от внутренних механизмов YouTube Music и могут требовать обновления после изменений со стороны YouTube.
